# 第七章 异常和文件

## 1. 异常

### 1.1 异常的基本概念

#### 1）什么是异常

**异常（Exception）** 指程序在运行过程中发生的**错误事件**。

例如：

```python
print(10 / 0)
```

运行结果：

```python
ZeroDivisionError: division by zero
```

异常的本质：   程序执行过程中出现了**无法继续执行的错误**

常见异常类型：

| 异常类型          | 说明       |
| ----------------- | ---------- |
| NameError         | 变量未定义 |
| TypeError         | 类型错误   |
| IndexError        | 索引越界   |
| ZeroDivisionError | 除零错误   |
| FileNotFoundError | 文件不存在 |

------

#### 2）未处理异常

如果程序没有对异常进行处理：

```python
异常发生
↓
Python解释器打印错误
↓
程序终止
```

例如：

```python
print("start")
print(10/0)
print("end")
```

输出：

```python
start
ZeroDivisionError
```

`end` 不会执行。

------

### 1.2 异常处理机制

Python使用 **try-except结构** 捕获异常。

#### 基本语法

```python
try:
    可能发生异常的代码
except 异常类型:
    异常处理代码
```

示例：

```python
try:
    result = 10 / 0
except ZeroDivisionError:
    print("除数不能为0")
```

执行流程：

```python
执行try代码
      │
      ├─没有异常 → 程序继续
      │
      └─发生异常 → 执行except
```

------

### 1.3 多异常捕获

一个程序可能出现多种异常。

例如：

```python
try:
    l = []
    print(l[10])
except NameError:
    print("变量未定义")
except IndexError:
    print("索引越界")
except ZeroDivisionError:
    print("除数不能为0")
```

执行机制：

```python
try代码执行
↓
发生异常
↓
按顺序匹配except
↓
执行匹配的处理代码
```

------

### 1.4 异常对象

异常不仅是一个错误提示，本质上是一个 **对象**。

可以使用 `as` 获取异常对象：

```python
try:
    print(10/0)
except Exception as e:
    print("发生异常:", e)
```

输出：

```python
发生异常: division by zero
```

异常对象中包含：

- 异常类型
- 错误信息
- 调用栈信息

------

### 1.5 Exception父类

Python异常体系：

```python
BaseException
      │
   Exception
      │
 ┌────┼────┐
TypeError
IndexError
ValueError
ZeroDivisionError
```

因此：`except Exception:`  可以捕获所有普通异常。

但在实际开发中：**不建议滥用**

应该优先捕获 **具体异常类型**。

------

### 1.6 else 与 finally

完整异常结构：

```python
try:
    代码块
except:
    异常处理
else:
    没有异常时执行
finally:
    无论如何都会执行
```

执行流程：

```python
try
 │
 ├─出现异常 → except
 │
 └─没有异常 → else

最后 → finally
```

------

### 1.7 异常传播

如果函数内部没有处理异常：   异常会 **向调用者传播**。

示例：

```python
def fn():
    print(10/0)

def fn2():
    fn()

def fn3():
    fn2()

fn3()
```

传播路径：

```python
fn
↓
fn2
↓
fn3
↓
主程序
```

如果最终没有捕获：**程序终止**

------

### 1.8 抛出异常

程序可以 **主动抛出异常**。

语法：

```python
raise Exception("错误信息")
```

示例：

```python
def add(a,b):

    if a < 0 or b < 0:
        raise Exception("参数不能为负数")

    return a + b
```

作用：**通知调用者发生错误**

------

### 1.9 自定义异常

开发中经常创建自定义异常。

语法：

```python
class MyError(Exception):
    pass
```

使用：

```python
raise MyError("自定义错误")
```

优势：

- 增强代码可读性
- 区分不同业务错误

------

### 1.10 异常处理最佳实践

推荐写法：

```python
try:
    with open("data.txt") as f:
        data = f.read()
except FileNotFoundError:
    print("文件不存在")
except PermissionError:
    print("没有访问权限")
except Exception as e:
    print("未知错误:", e)
```

原则：

- 先捕获具体异常
- 最后捕获通用异常

## 2. Python文件操作（File I/O）

### 2.1 文件操作基本流程

文件操作遵循三个步骤：

1. 打开文件
2. 操作文件
3. 关闭文件

对应代码：

```python
file = open("demo.txt")

content = file.read()

file.close()
```

------

### 2.2 open()函数

#### 基本语法

```python
open(file, mode='r', encoding=None)
```

参数说明：

| 参数     | 说明     |
| -------- | -------- |
| file     | 文件路径 |
| mode     | 打开模式 |
| encoding | 编码格式 |

------

### 2.3 文件打开模式

| 模式 | 说明     |
| ---- | -------- |
| r    | 只读     |
| w    | 写入     |
| a    | 追加     |
| x    | 创建     |
| b    | 二进制   |
| t    | 文本模式 |

------

#### w模式

特点：

- 文件不存在 → 创建
- 文件存在 → 清空文件

示例：

```python
with open("test.txt","w") as f:
    f.write("hello")
```

------

#### a模式

追加模式：  写入内容**追加**到文件末尾

示例：

```python
with open("test.txt","a") as f:
    f.write("hello")
```

------

#### x模式

安全创建文件：  文件存在 → 报错

示例：

```python
open("test.txt","x")
```

------

### 2.4 with语句

推荐使用：

```python
with open("demo.txt") as f:
    content = f.read()
```

优势：

- 自动关闭文件
- 避免资源泄露
- 代码更安全

------

## 3. 文件读取

### 3.1 read()

读取整个文件。

```python
content = file.read()
```

特点：

- 返回**字符串**
- **一次性**读取全部内容

缺点：

- 大文件可能占用**大量**内存

------

### 3.2 readline()

**一次读取一行**

```python
line = file.readline()
```

示例：

```
A
B
C
```

执行：

```python
readline → A
readline → B
readline → C
```

------

### 3.3 readlines()

**读取所有行并返回列表**

```python
lines = file.readlines()
```

返回：

```python
['A\n','B\n','C\n']
```

------

### 3.4 最推荐读取方式

使用 **for循环**：

```python
with open("demo.txt") as f:
    for line in f:
        print(line)
```

优点：

- 逐行读取
- 内存占用低
- 适合大文件

------

## 4. 大文件读取策略

处理大文件时：

不要使用：`read()`

推荐 **分块读取**。

示例：

```python
with open("big.txt") as f:

    while True:

        chunk = f.read(1024)

        if not chunk:
            break

        print(chunk)
```

原理：

- 每次读取固定大小
- 避免内存溢出

------

## 5. 二进制文件操作

文本文件：

- txt
- csv
- json

二进制文件：

- 图片
- 音频
- 视频

打开方式：

- **rb 读取**
- **wb 写入**

------

#### 文件复制示例

```python
with open("source.jpg","rb") as f:
    with open("copy.jpg","wb") as new:

        while True:

            data = f.read(1024)

            if not data:
                break

            new.write(data)
```

## 6. 文件指针

文件内部有一个 **读取位置指针**。

示意：

```python
文件内容
A B C D E F

指针
  ↑
```

------

#### tell()

查看当前读取位置：

```python
file.tell()
```

返回：**当前字节位置**

------

#### seek()

移动指针：

```python
file.seek(offset,whence)
```

参数：

| whence | 含义     |
| ------ | -------- |
| 0      | 文件开头 |
| 1      | 当前位置 |
| 2      | 文件末尾 |

示例：

```python
file.seek(10)
```

表示：跳到第10个字节
