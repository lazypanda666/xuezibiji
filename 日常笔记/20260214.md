# 谓词逻辑

### 1. 谓词的概念与表示

- 谓词：刻划客体性质或客体间关系的词。
  - 一元谓词：表示客体性质（如$$ A (x)$$：x 是大学生）。
  - n 元谓词：表示 n 个客体间的关系（如$$ L (x,y)$$：x 在 y 与 z 之间）。
- **谓词填式**：谓词后填入客体名称得到的命题（如 $$A (c)$$：张三是大学生）。

### 2. 命题函数与量词

- **命题函数**：由谓词和客体变元组成的表达式（简单命题函数：$$H (x)$$；复合命题函数：$$S (x)∧W (x)$$。)
- **个体域**：客体变元的论述范围（全总个体域：包含所有客体的论域）。
- 量词：
  - 全称量词（$$∀$$）：表示 “对所有的” “每一个”，$$∀xP (x)$$ 表示所有 x 满足 $$P (x)$$。
  - 存在量词（$$∃$$）：表示 “存在一些”“至少有一个”，$$∃xP (x)$$ 表示存在 x 满足 $$P (x)$$。
- **特性谓词**：限定客体变元范围的谓词，全称量词后作蕴含前件，存在量词后作合取项。

### 3. 谓词公式与翻译

- **原子谓词公式**：$$A (x₁,x₂,...,xₙ)$$（n 元谓词 + 客体变元）。
- 合式公式定义：
  1. 原子谓词公式是合式公式。
  2. 若 A 是合式公式，则$$ ¬A$$ 是合式公式。
  3. 若 A、B 是合式公式，则$$ (A∧B)、(A∨B)、(A→B)、(A↔B) $$是合式公式。
  4. 若 A 是合式公式，x 是 A 中变元，则$$ (∀x) A、(∃x) A$$ 是合式公式。
  5. 有限次应用 1-4 得到的是合式公式。

### 4. 变元的约束

- **约束变元**：被量词指导变元约束的变元（如$$ (∀x) P (x)$$ 中 x）。

- **自由变元**：未被约束的变元（如 $$(∀x) P (x,y) $$中 y）。

- 换名规则（约束变元）：

  - 更改量词指导变元及作用域中所出现的该变元。

  - 新变元不得在作用域中出现。

- 代入规则（自由变元）：

  - 代入所有自由出现的该变元。

  - 代入变元与原公式中变元名称不同。

### 5. 谓词演算的等价式与蕴含式

- **命题公式推广**：命题演算中的等价式和蕴含式可推广到谓词演算。
- **量词转化律**：$$¬(∀x)P(x)⇔(∃x)¬P(x)；¬(∃x)P(x)⇔(∀x)¬P(x)$$。
- 量词作用域扩张与收缩：
  - $$(∀x)(A (x)∨B)⇔(∀x) A (x)∨B$$
  - $$(∃x)(A (x)∧B)⇔(∃x) A (x)∧B $$
- 量词分配律：
  - $$(∀x)(A(x)∧B(x))⇔(∀x)A(x)∧(∀x)B(x)$$
  - $$(∃x)(A(x)∨B(x))⇔(∃x)A(x)∨(∃x)B(x)$$

### 6. 前束范式

- **定义**：量词均在全式开头，作用域延伸到末尾的公式（如 $$(∀x)(∃y)(P (x,y)→Q (x,y))$$）。
- 转化步骤：
  1. 否定深入到命题变元和谓词填式前。
  2. 更改约束变元名称。
  3. 量词移到全式开头。

### 7. 谓词演算的推理理论

- 推理规则：
  - US（全称指定）：$$(∀x) P (x)⇒P (c)$$（c 为任意客体）。
  - UG（全称推广）：$$P (x)⇒(∀x) P (x)$$（x 遍历所有客体）。
  - ES（存在指定）：$$(∃x) P (x)⇒P (c)$$（c 为特定客体）。
  - EG（存在推广）：$$P (c)⇒(∃x) P (x)$$（c 为客体）。
- **推理注意事项**：ES 需在 US 前使用；同一推理中，ES 指定的客体 c 需一致。

# 集合与关系

### 1. 集合的概念和表示法

- **集合定义**：具有共同性质的客体汇集成的整体。

- 表示法：

  - 列举法：A={a,b,c}；B={1,2,3,...}。
  - 叙述法：S={x|x 是正奇数}。

- 核心概念：

  - 子集（⊆）：$$A⊆B⇔∀x (x∈A→x∈B)$$，自反性$$（A⊆A）$$、传递性

    （$$A⊆B 且 B⊆C 则 A⊆C$$）。

  - 真子集（⊂）：$$A⊂B⇔A⊆B 且 A≠B$$。

  - 空集（∅）：不包含任何元素，∅⊆任意集合。

  - 全集（E）：包含所有讨论客体的集合。

  - 幂集（P (A)）：由 A 的所有子集组成的集合，若 $$| A|=n，则 | P (A)|=2ⁿ$$。

### 2. 集合的运算

|   运算   | 符号  |        定义         |
| :------: | :---: | :-----------------: |
|    交    | $$∩$$ |  $$A∩B={x∈A∧x∈B}$$  |
|    并    | $$∪$$ |  $$A∪B={x∈A∨x∈B}$$  |
|  绝对补  |   ~   |  ~A=E-A={x∈E∧x∉A}   |
| 补（差） | $$-$$ |  $$A-B={x∈A∧x∉B}$$  |
|  对称差  | $$⊕$$ | $$A⊕B=(A-B)∪(B-A)$$ |

重要定理：

- 吸收律：$$A∪(A∩B)=A；A∩(A∪B)=A$$
- 分配律：$$A∩(B∪C)=(A∩B)∪(A∩C)；A∪(B∩C)=(A∪B)∩(A∪C)$$

### 3. 包含排斥原理

- **二元情况**：$$|A∪B|=|A|+|B|-|A∩B|$$
- **三元情况**：$$|A∪B∪C|=|A|+|B|+|C|-|A∩B|-|A∩C|-|B∩C|+|A∩B∩C|$$
- **n 元情况**：$$|A₁∪A₂∪...∪Aₙ|=Σ|Aᵢ|-Σ|Aᵢ∩Aⱼ|+Σ|Aᵢ∩Aⱼ∩Aₖ|-...+(-1)ⁿ⁻¹|A₁∩...∩Aₙ|$$

### 4. 序偶与笛卡尔积

- **序偶**：$$<x,y>$$，具有次序，$$<x,y>=<u,v>⇔x=u 且 y=v$$。
- **笛卡尔积**：$$A×B={<x,y>|x∈A∧y∈B}$$
  - 性质：$$A×(B∪C)=(A×B)∪(A×C)；(A∪B)×C=(A×C)∪(B×C)$$
  - 注意：$$A×B≠B×A$$（除非 $$A=∅$$或 $$B=∅$$或$$ A=B$$）
